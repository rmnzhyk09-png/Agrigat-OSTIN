## 🚀 Как запустить (для новичков)

### Шаг 1: Установи Python

Скачай и установи Python 3.11+ с официального сайта:
👉 https://www.python.org/downloads/

При установке **обязательно** поставь галочку **"Add Python to PATH"**.

### Шаг 2: Открой PowerShell

Нажми `Win + R`, введи `powershell` и нажми Enter.

### Шаг 3: Зайди в папку проекта

```powershell
cd "C:\Users\Hp\OneDrive\Desktop\роект 118\unified-monitor"
```

### Шаг 4: Создай виртуальное окружение

```powershell
python -m venv .venv
```

### Шаг 5: Активируй окружение

```powershell
.\.venv\Scripts\Activate.ps1
```

> Если выдаст ошибку выполнения скриптов, выполни:
> ```powershell
> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

### Шаг 6: Установи зависимости

```powershell
pip install -r requirements.txt
```

### Шаг 7: Создай файл .env

Создай файл `.env` (без расширения) в папке `unified-monitor` и добавь туда:

```env
BOT_TOKEN=твой_токен_от_BotFather
```

> 📝 Как получить токен:
> 1. Напиши в Telegram боту **@BotFather**
> 2. Нажми `/newbot`
> 3. Придумай имя и юзернейм для бота (например: `MyMonitorBot`)
> 4. Скопируй полученный токен и вставь в `.env`

### Шаг 8: Запусти бота

```powershell
python -m bot.main
```

Готово! Бот запустился и работает в режиме polling.

## 🎮 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и список команд |
| `/find <запрос>` | 🌍 **Глобальный поиск** по всем соцсетям + RSS + веб (любая фраза) |
| `/tag <тег>` | 🏷 **Поиск по хештегу** (например: `/tag криптовалюта`) |
| `/web <запрос>` | 🌐 **Универсальный веб-поиск** (Google через Serper / SerpAPI / Brave) |
| `/rss <url>` | 📰 Прочитать любую RSS-ленту |
| `/scrape <url>` | 🕸 Скрапер страницы сайта (robots.txt, без обхода авторизации) |
| `/import` | 📥 Импорт файла БД (SQLite/CSV/JSON/Excel/txt, ZIP/RAR, торренты) в собственную БД с авто-сортировкой по разделам |
| `/monitor` | Поиск с выбором режима кнопками: глобальный / тег / аккаунт |
| `/catalog` | Каталог OSINT-ботов |
| `/groups` | Список групп ботов |
| `/bot <группа>` | Боты в группе (например: `/bot telegram`) |
| `/info <название>` | Карточка бота (например: `/info himera`) |
| `/search <запрос>` | Поиск в каталоге ботов |
| `/history` | История поиска |
| `/report` | Последний отчёт |
| `/status` | Статус задач |
| `/tags` | Управление тегами |
| `/subscribe` | Подписка на дайджест |
| `/cancel` | Отмена текущего действия |

Каждый мониторинг (`/find`, `/tag`, `/monitor`, `/web`) присылает: сводку,
**график PNG** (платформы, тональность, теги), **PDF-отчёт**, JSON, CSV и Markdown.

## 📥 Импорт файла БД (`/import`)

Пришлите боту файл базы данных — скрипт разберёт записи, определит категорию
(субъект) каждой записи по ключевым словам и сохранит результат в собственную БД.

- **Форматы:** SQLite (`.db`/`.sqlite3`), CSV, JSON (включая Telegram export),
  Excel (`.xlsx`), текст (`.txt`), архивы ZIP/RAR (внутри разбираются БД, CSV,
  Excel, txt и торренты, в т.ч. вложенные), торренты `.torrent`
  (имя раздачи, файлы и размеры, трекеры, SHA1 + magnet-ссылка)
- **Как работает:** текст записи берётся из колонок `text / message / content`,
  автор — `author / from / user`, дата — `date / created_at`
- **Разделы:** при обнаружении новой категории автоматически создаётся новый
  раздел (таблица `db_sections`), записи складываются в `db_records`
- **Поиск по БД:** импортированные записи участвуют в `/find`, `/tag`, `/monitor`
  и `/web` — результат помечается платформой «База импорта»
- **Supabase (опционально):**
  1. В Supabase выполни скрипт `supabase/schema.sql` (SQL Editor)
  2. В `.env` пропиши `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`
  3. Для авто-создания таблиц добавь `SUPABASE_PROJECT_REF` и `SUPABASE_ACCESS_TOKEN`
- Без ключей данные сохраняются локально (SQLite/Postgres, таблицы `db_*`)

## 🛠️ Настройка API-ключей (опционально)

Бот работает и без API-ключей, но с ограничениями. Для полного функционала добавь в `.env`:

```env
# X/Twitter
TWITTER_BEARER_TOKEN=твой_bearer_token

# Reddit
REDDIT_CLIENT_ID=твой_client_id
REDDIT_CLIENT_SECRET=твой_client_secret

# GitHub
GITHUB_TOKEN=твой_token
```

Без ключей бот работает в упрощённом режиме.

## ❓ Частые вопросы

**Q: Ошибка `Cannot connect to host api.telegram.org:443` / «Превышен таймаут семафора»?**
A: Провайдер блокирует Telegram API. Включи VPN или укажи прокси в `.env`:
```env
PROXY_URL=http://127.0.0.1:8080
# или SOCKS5:
PROXY_URL=socks5://127.0.0.1:1080
```
Порт возьми из настроек своего VPN/прокси-приложения (например, в v2rayN — «Настройки → HTTP-порт»).

**Q: Бот не запускается, ошибка "ModuleNotFoundError"?**  
A: Убедись, что активировал виртуальное окружение и установил зависимости.

**Q: Бот не отправляет сообщения?**  
A: Проверь, что правильно ввёл `BOT_TOKEN` в `.env`.

**Q: Нет данных по мониторингу?**  
A: Без API-ключей сбор данных ограничен. Добавь ключи для полного функционала.

**Q: Как обновить бота?**  
A: Выполни `git pull` (если из git) и заново установи зависимости через `pip install -r requirements.txt`.
