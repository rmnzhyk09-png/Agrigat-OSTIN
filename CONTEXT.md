## Что НЕ трогать / помнить
- **`_window()`/`DB_LOCAL_WINDOW` мы НЕ меняли** — пользователь против обрезки поиска по БД. Поиск должен идти по всей базе (все файлы). Локальные лимиты `limit=20`/`limit=5` — только на выдачу, не на охват.
- **Не изменять охват/обрезку поиска** — это чувствительная тема для пользователя.
- Не коммитить `.env`, `.env.txt`, `.env.local` (в .gitignore). `.env.example` — без секретов, ок.
- Не вставлять реальные ключи в код/README/коммиты.

5. У пользователя ДВА supabase-проекта (qokujzqkeprvqnoxviuc — primary, лежит в recovery `57P03 hot standby`; jzvmxqsfailsjqjkuxyb — #2, ACTIVE_HEALTHY). Реальные 2.1M записей — в локальном зеркале и в упавшем primary; пока primary в recovery, поиск работает через фан-аут ##+локальное зеркало.
